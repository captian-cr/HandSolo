# 第一次用：先把它调成你的手（约 2 分钟）

> **请先做完这一步再用。** 这套系统的每个阈值都是按**一个人的手**标定的，
> 作者的手不等于你的手。跳过这一步，你会觉得"能识别但不好用"——
> 那不是 bug，是拿别人的尺子量你。

---

## 怎么开始

双击项目目录里的 **`HandSolo（首次设置）.bat`**，或者：

```powershell
cd "<项目目录>"
python -m handmouse --onboarding
```

> 🔴 PowerShell 里**不要**写 `cd /d`——那是 cmd 的写法，会报
> `找不到接受实际参数…的位置形式参数`。紧接着那条 `python -m handmouse` 会**在原目录**
> 执行、报 `No module named handmouse`。两个错连着出现时，先看第一条：cd 根本没成功。
> PowerShell 用 `cd "D:\路径"`；老式 cmd 才是 `cd /d D:\路径`。

全程**不会动你的鼠标**，随时按 `ESC` 退出（已录的内容不会保存）。

---

## 第一步：标定 3 个点 —— 圈出你的活动范围

画面上会出现一个**黄色十字**，一共标 **3 个点**，按顺序是
**屏幕中央 → 屏幕左上 → 屏幕右下**。每标完一个点，十字会换成下一个。

> 🔴 **先看清楚这句话：十字不是让你把手放上去。**
>
> 十字只表示**"这个点在屏幕上的哪个方位"**。要标的是：
>
> **你的手放在你自己觉得最舒服的位置，捏合一下。**
>
> 程序会把你捏合的位置，当成"对应屏幕上那个点"的位置记住。
> 你不需要去够十字，也不需要迁就任何坐标——**你捏在哪儿，就以哪儿为准。**

捏合成功时十字会**变绿**，保持约 0.2 秒完成，然后自动进下一个点。
每个点有约 20 秒，来不及也没关系：没确认的点会被跳过，不影响其它点。

**三个点用来做什么？** 它们圈出你愿意用的范围：

- 程序取这三个点形成的矩形，再放大 25% 当**活动区**；
- 活动区的中心 = 三点中间 → 手停在中间时，光标在屏幕正中；
- 于是"抬手够屏幕顶"和"落手够屏幕底"的行程一样，两边都不别扭。

> 三个点要是捏得几乎在同一处，程序会认为"你没在给范围"，
> 退回"只按中心 + 默认大小"，免得把全屏映射到几厘米的手部移动上（那会一碰就飞）。

## 第二步：量速率 —— 记录你自己的习惯

接下来屏幕上会提示你**像平时那样左右移动手指**（7 秒）。

> 别赶时间，也别刻意放慢。**我要记录的是你自己习惯的速度**，
> 不是标准动作。你平时怎么动，就怎么动。

程序统计你手部移动速度的中位数与 p90，存进
`gesture_data\onboarding.json`，并给出一个"偏慢 / 中等 / 偏快"的判断。

> ⚠️ 这一步**只记录，不自动改参数**。因为"该给偏快的手调多少"这件事，
> 目前只在作者一个人身上验证过，多几个人验证之后才会自动应用。
> 现阶段它用于：诊断（你的手感问题是不是速度不匹配）、以及论文里的个体差异分析。

## 第三步：每种手势过一遍（每步都等你确认）

七种手势，每一个都分三段：

1. **看题目**：屏幕显示这一步要做什么，**不计时，等你看完**；
2. **确认**：你觉得准备好了，就**捏合一下**（或按空格 / 回车）；
3. **开始录**：准备 2 秒 → 练习 5 秒。

| 顺序 | 手势 | 题目 |
|---|---|---|
| 1 | 移动 | 就像平时操控光标那样，用【移动】手势随便动一动 |
| 2 | 停住 | 用【停住】手势，保持不动即可 |
| 3 | 捏合 | 反复捏合、松开，像平时点击那样 |
| 4 | 五指张开 | 五指张开，随意保持 |
| 5 | 握拳 | 握拳，随意保持 |
| 6 | 双指 | 保持食指+中指伸开、其余握拳，缓慢转动手腕 |
| 7 | 双指（补） | 同上，换一个手腕角度或手的高度 |

> 🔴 为什么要有"捏合确认"这一步：第一版是**硬倒计时 2 秒**，用户还没读完题目
> 就已经开始录了——录进去的全是"还在找题"的帧，既污染样本又让人被催得手忙脚乱。
> 现在改成"你捏合了才开始"。
>
> 某一步不想做：等 120 秒它会自动开始（不会卡死），或者按 `ESC` 退出整个录制。

这一段有三重作用：**教你一遍、让你适应一遍、同时把这些姿势录成你自己的样本库**。
录完的样本用于"认得出是你的手"，模型在遇到不像你的姿势时会**拒绝识别**，
而不是硬猜。

## 结束

完成后会打印存了多少帧、写到哪个文件，并自动：

- 把你的舒适点换算成 `config.json` 里的 `pointer_margin_*`；
- 用样本库算出**拒识阈值**并打开手势库（`gesture_model_enabled`）；
- 记一笔 `onboarding_done = true`（之后启动不再提醒你）。

> 向导自己的那个窗口走完会自动关掉。**日常使用时**如果不想看见预览窗：
> 运行中按 `P` 或 `Ctrl+Alt+P` 随时关/开；一开始就不想要就双击
> `HandSolo（后台无预览）.bat`。关掉后状态看光标旁的小圆环（颜色见 README）。

以后想补录（比如双指在某个角度还认不出来）：

```bat
python -m handmouse.collect --append
```

`--append` 是**追加**，不会覆盖你已有的样本。

## 常见问题

**十字一直在、捏合没反应？**
捏合要拇指尖靠近食指尖（距离 ÷ 掌宽 ≤ `pinch_engage`，默认 0.42）。
先确认预览窗里能看到你的骨架；看不到就是手没进画面，或者摄像头被别的软件占着。

**我中途退出了，重来会丢东西吗？**
不会。已经算出的舒适点、速率都在内存里，只有全部走完才写盘；
中途退出等于什么都没改，重跑一次就行。

**录完之后反而更难用了？**
把 `config.json` 里 `gesture_model_enabled` 改成 `false` 先关掉样本库，
判据会退回几何版本。然后跑 `python -m handmouse.collect --append` 多补几个角度
（尤其是"手指快指向镜头"和"手放低到画面下方"这两个极端）。
