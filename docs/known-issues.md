# Known Issues

## KI-001 左手用户进入控制态被延迟（镜像模式）

**症状**：镜像模式（`config.mirror=True`）下，左手用户手掌进入画面后，
闸门可能数秒不开。实测最长 7.7s / 53 帧无恢复。

**根因**：MediaPipe HandLandmarker 的 handedness 在追踪链存活期内可能
冻结在入链首帧的判定。镜像模式下左手在模型输入帧里长得像右手，
首帧若被误判为 Left，该标签可能在链存活期内冻结；冻结非绝对——
另有一轮同机制下 1 帧即自愈，冻结触发条件比「链存活」更窄，未明。

**恢复条件**：确认有效的纠正事件是追踪中断（丢手 ≥ ~200ms 后重检），
实测 55ms 中断即翻正，与等待时长无关；偶发链内自愈（1 帧）不可依赖。

**影响范围**：
- 仅左手 + 镜像模式
- 仅当入链首帧标签错误时
- 冻结时长随机（与追踪链何时中断有关）

**缓解**：出画再回、或晃手触发追踪中断。

**为什么不用几何量修（方向 2 出局）**：
几何量（`cross2d(k17−k5, k4−k5)`、`triple`）在掌姿势下能分左右手，
但背姿势下不能。更关键：L-back 与 R-palm 在 nz / cross2d / triple
三量上全部同号——左手背的 21 点 2.5D 几何与右掌互为投影同构，
MediaPipe 伪深度 z 不足以区分。

若用几何量替代 label 逐帧判定，左手背新鲜进入会被误判为右掌进入，
**H4（手背拒绝）从 PASS 退化为恒定误开**。用 H4 的退化换 ④ 的
修复，量级不对等，不采。

**状态**：挂起（documented，not fixed）。hn_score 门槛方案已排除
（正确锚首帧分布 0.600–0.998 完全覆盖错锚 0.665）。
